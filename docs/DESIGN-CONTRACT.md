# E2M Diwali — Build Contract (LOCKED, premium tier, version v1)

Output: `site/v1/` — plain static site, open via any static server. No build step, no backend.
Libraries (CDN, exact versions): gsap@3.12.5 + ScrollTrigger (cdnjs), three@0.160.0 (jsdelivr, ES module, ONLY for the opening diya/door glow if it adds value; otherwise skip). Fonts: Google Fonts — "Cormorant Garamond" (display serif, 500/600/700 + italic) and "DM Sans" (UI). Everything else inline/own files. No stock images: all art is custom inline SVG / canvas / CSS.

## Tokens (css/tokens.css, :root)
--navy #080B1E, --purple #241044, --saffron #FF9F32, --gold #FFD778, --magenta #DB59C8, --ivory #FFF4DC. Derived: --ember #E8641A, --teal-accent only for tiny contrast (#3FD0C9) sparingly, --glow-gold rgba(255,215,120,.55). Radii: mostly none/arch shapes (cusped Mughal arch, jharokha, onion dome), NOT generic rounded cards. Display headings Cormorant, UI DM Sans. Buttons: pill-less "diya-plate" shapes (clip-path arch top / gold hairline border, saffron fill, ivory text on navy), strong focus-visible ring.

## File layout
```
site/v1/index.html          shell, all section markup (mount points), loads scripts in order
site/v1/css/tokens.css base.css world.css zones.css   (each activity may ship css/act-<name>.css)
site/v1/js/core.js          window.E2M — shared engine (loaded first, non-module, defer)
site/v1/js/world.js         opening sequence, parallax scenery, scroll storytelling, finale
site/v1/js/act-<name>.js    one per activity, self-registering
```
Script order in index.html (all `defer`): gsap, ScrollTrigger, core.js, act-*.js (any order), world.js (last).

## Zone markup contract (index.html owns this; activities must NOT edit index.html)
Each zone: `<section class="zone" id="zone-<key>" data-zone="<key>"><header class="zone-head">…</header><div class="zone-stage" data-mount="<key>"></div></section>`
Keys / order: `fireworks`, `diyas`, `rangoli`, `laddoo`, `lanterns`, `chakri`, `gifts`, `angry`, `mood`, then `finale`.
Each activity file calls `E2M.register('<key>', { mount(stageEl){…}, onEnter(){…}, onLeave(){…} })`. core.js calls `mount` on DOMContentLoaded (after the opening is dismissed is fine — mount must be cheap), `onEnter/onLeave` when the zone is >35% in view (IntersectionObserver). Activities MUST pause rAF loops in onLeave and when `document.hidden`. All activities build their own DOM inside stageEl (stage fills the zone width; min-height ~ 80vh; mobile friendly, touch targets ≥44px, pointer events not mouse-only, `touch-action` set sensibly so page still scrolls where not a drag surface).

## window.E2M API (core.js provides; activities consume)
- `E2M.reduced` boolean (prefers-reduced-motion), `E2M.mobile` boolean (coarse pointer or width<760), `E2M.maxParticles` (desktop 900, mobile 350, reduced 150).
- `E2M.register(key, spec)`, `E2M.on(evt, fn)`, `E2M.emit(evt, data)`. Events used: `diyas:allLit`, `finale:start`, `sound:toggle`.
- `E2M.audio`: `.enabled` (false until user toggles; NEVER autoplay), `.toggle()`, `.play(name)` where name ∈ `bell, pop, whoosh, boom, crackle, sparkle, thud, win, lose, chime, spin, finale`. All synthesized with WebAudio (no files). No-op when disabled.
- `E2M.fx`: shared overlay canvas fixed full-viewport `pointer-events:none`, z-index above content below UI: `.confetti(x,y,n?)`, `.petals(n?)` (falling marigold/rose petals, self-expiring), `.sparkBurst(x,y,color?,n?)`, `.firework(x,y,opts?)` (opts: color|'multi', size, ring/heart/willow type), `.fireworkShow(durationMs)`, `.goldenRain()`. Particle pools capped by E2M.maxParticles; one rAF loop that idles (stops) when nothing alive.
- `E2M.score`: `.get(key)`, `.setBest(key,val)` (localStorage `e2m-diwali:<key>`, try/catch wrapped), returns boolean new best.
- `E2M.toast(msg)`: small funny microcopy toast, bottom center.
- `E2M.rand(a,b)`, `E2M.pick(arr)`, `E2M.svg(htmlString)` helper.
- Hidden collectibles: `E2M.found(id)` increments a "hidden diyas found x/7" counter shown in the HUD (world.js creates HUD).
- `E2M.state.diyas` (array of lit flags), `E2M.lightAllDiyas()` and `E2M.rangoliAnimate()` are defined by act-diyas / act-rangoli and called by the finale — define as `E2M.lightAllDiyas = fn`, `E2M.rangoliAnimate = fn`, `E2M.releaseLanterns = fn` (the finale in world.js calls them if present).
- Cursor trail: core.js, golden particles, desktop fine pointer only, off when reduced.

## Shared visual language
Night courtyard: layered SVG silhouettes (palace, domes, arches, jharokhas) with parallax; strings of marigold garlands and hanging bells; star field; every zone gets a distinct "destination" backdrop (not rectangles): fireworks = open night sky with palace skyline; diyas = courtyard floor with rangoli; rangoli = ivory-on-navy drafting floor/mandala table; laddoo = sweet-shop awning/mithai stall; lanterns = sky corridor; chakri = dark ground with spark pit; gifts = a row of ornate decorated boxes on a carpet with zari border; angry = shrine-niche (taak) with the diya character; mood = a rotating mandala "oracle" with the result card. Microcopy: playful, funny, short. Hover = warm illumination (radial gold glow follows pointer on interactive things).
Accessibility: semantic landmarks, one h1, buttons are real `<button>`, aria-labels on canvases/games, visible focus, keyboard alternatives for all drags (arrow keys), `@media (prefers-reduced-motion)` fallback (no autoplay loops, particles minimal, game still playable).

## Quality bar
Every visible control works. No console errors. No horizontal scroll at 375/768/1280. No placeholder text. Games: start, timer, score, restart, final screen with funny message, best score persisted. Activities isolate their CSS under `.act-<key>` to avoid collisions.

## R3.1 Real fireworks sound (A4, core.js `E2M.audio`)
Do not ship thin oscillator beeps. Build a procedural-but-realistic engine on WebAudio: a shared master chain with a generated convolution reverb (decaying noise impulse, ~2.5s, lowpassed) for open-air tail; launch = rocket whoosh/whistle (bandpassed noise with rising filter + faint rising sine, short crackly fuse hiss); burst = layered: sharp transient click (noise burst ~5ms), low "thump" body (sine/sub drop 120→35Hz, fast decay), mid "crack" (noise bandpass 1–4kHz, 120ms), then a long reverb tail; crackle/sizzle after-burst = dozens of randomised micro noise ticks (like crossette/crackling willow) spread over 0.4–1.2s; DISTANCE model: far bursts are delayed by distance (up to ~0.9s for the far layer, speed-of-sound feel), lowpassed (cutoff falls with distance), quieter, more reverb; near bursts are punchy, loud, short delay. Pitch/size variation per size (small = higher, crisp; large = deeper, longer tail), slight random detune so no two sound identical. Rapid-fire limiter (max ~10 concurrent voices, compressor on master). Provide `E2M.audio.play('launch',{size})`, `('burst',{size:0..1, distance:0..1})`, `('crackle',{size,distance})`, `('chakri')` (a continuous whirring hiss with pitch tied to RPM: `E2M.audio.loop('chakri',{rate})` returns a handle with `.set(rate)` `.stop()`), plus existing names kept (bell, pop, chime, win, thump, rumble, flick…). Sound stays OFF until the user enables it; respect volume pref. Ambient background bursts (R3.3) are sound-enabled only and use far/mid distance at low gain.
